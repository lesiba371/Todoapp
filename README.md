# Todoapp

A simple, clean Todo application built with **React**, **TypeScript**, and **Vite**.

## Features

- ✅ Add new todos (via button click or Enter key)
- ✔ Mark todos as complete/incomplete
- 🗑 Delete individual todos
- 🔍 Filter by All / Active / Completed
- 🧹 Clear all completed todos at once
- 💾 Persists todos in localStorage
- 📱 Responsive design

## Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Install dependencies

```bash
npm install
```

### Run in development mode

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Run tests

```bash
npm test
```
